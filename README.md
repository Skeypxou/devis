
# Atelier PVC Pro

Application Streamlit en français pour la gestion des clients, devis, calculs de métrage PVC, vitrage, accessoires, factures, paiements et PDF.

## Fonctionnalités de cette première version

- Gestion des clients.
- Catalogue de profilés PVC, vitrages et accessoires.
- Calcul du métrage selon le nombre de vantaux.
- Calcul de la surface et du prix du vitrage.
- Création et historique des devis.
- Conversion d'un devis accepté en facture.
- Suivi des paiements.
- Génération de PDF.
- Export et restauration d'une sauvegarde JSON.
- Stockage JSON local et option Supabase pour le stockage persistant en ligne.

## Démarrage local (Windows)

Installer Python 3.11 ou 3.12, puis dans le dossier du projet :

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
```

Si PowerShell bloque l'activation, lance la commande d'activation depuis `cmd.exe` ou utilise directement :

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

## GitHub et Streamlit Community Cloud

1. Crée un dépôt GitHub et ajoute les fichiers du projet.
2. Vérifie que `data/*.json` et `.streamlit/secrets.toml` ne sont pas publiés.
3. Dans Streamlit Community Cloud, crée une application liée au dépôt, à la branche et à `app.py`.
4. Clique sur Deploy.

### Persistance des données en ligne avec Supabase

Le disque local de Streamlit Community Cloud n'est pas un stockage persistant garanti. Pour conserver les données entre redémarrages, crée un projet Supabase puis exécute cette requête SQL dans son éditeur SQL :

```sql
create table if not exists public.app_data (
  id bigint generated by default as identity primary key,
  collection text unique not null,
  payload jsonb not null default '[]'::jsonb
);
```

Dans les secrets de l'application Streamlit, ajoute :

```toml
[supabase]
url = "https://VOTRE-PROJET.supabase.co"
key = "VOTRE_CLE_SUPABASE"
```

Utilise une clé serveur appropriée pour l'application et ne la publie jamais sur GitHub. Pour un déploiement public multi-utilisateur, ajoute une authentification et des règles d'accès avant d'y stocker de vraies données clients.

## Important sur le calcul PVC

La règle commerciale actuelle :
- 1 vantail : périmètre du cadre seul.
- 2 vantaux ou plus : cadre + deux horizontales par vantail (largeur divisée par le nombre de vantaux) + deux verticales par vantail (hauteur complète).

Ces formules sont des estimations commerciales configurables et ne remplacent pas la nomenclature technique du fabricant de profilés.
